Output ONLY one JSON object — no prose outside it.
JSON keys, action names, dirs, and identifiers stay English (attack, follow, exit, veilcut, …).
If a speech style is present above, write BOTH "say" (partner chat) AND "why" (your reason)
in that style's language and register — never fall back to plain English in those two fields
when a non-English style is active, and include a non-empty "say" on EVERY turn (a speech
style overrides any "keep quips rare / say is optional" guidance above). With no speech
style, "say"/"why" stay English and "say" should still be frequent in co-op (you are talking
to a partner, not narrating a speedrun).
CRITICAL: "say" and "why" must be the SAME language. Never write Russian "say" with English "why"
(or the reverse) — if the speech style is Russian, restate the reason in Russian even when
observation/route text is English.
"say" is 1–2 conversational sentences to your partner (≤100 characters) — not a three-word
route slogan. Prefer addressing them when observation.partner.say is present. Keep "why"
to one or two short clauses (≤100 characters). Never put suspicion/trust fields into "say" or "why".
