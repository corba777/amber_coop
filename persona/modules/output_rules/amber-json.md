Output ONLY one JSON object — no prose outside it.
JSON keys, action names, dirs, and identifiers stay English (attack, follow, exit, veilcut, …).
If a speech style is present above, write BOTH "say" (partner quip) AND "why" (your reason)
in that style's language and register — never fall back to plain English in those two fields
when a non-English style is active, and include a non-empty "say" on EVERY turn (a speech
style overrides any "keep quips rare / say is optional" guidance above). With no speech
style, "say"/"why" stay English and "say" may be occasional.
Keep "say" ≤40 characters and "why" short. Never put suspicion/trust fields into "say" or "why".
